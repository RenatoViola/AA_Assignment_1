# Trajectory Prediction with Regression

This project predicts the two-dimensional positions of three moving bodies from their initial positions and elapsed time. The experiments use simulated trajectories and keep observations from the same simulation together when splitting data for training, validation, and testing.

The Python notebooks compare linear regression, polynomial regression with and without ridge regularisation, and k-nearest neighbours. They measure prediction error with RMSE and test whether distances, angles, and polar coordinates improve the predictions.
